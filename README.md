## Featurs/Commands
- `joseph-ping` - Check if Joseph hasn't died... again
- `joseph-hermit`- Use Joseph's stand: Hermit Purple to find out/get public data about a user in your Slack workspace.
- `joseph-sp` - Use Joseph's stand: Hermit Purple to get the public profile picture of a user in your Slack workspace.
- `joseph-story` - Hear a bit about Joseph's Bizzarre Adventures
- Joseph has grown old, so he sometimes can have hearing issues.

## Running Locally
1. Clone the repo.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Create an .env file as per my .env.example file:
4. Start the bot:
   ```node index.js```
